# Gestion des Absences Mobile

Gestion des Absences Mobile est une application Android conçue pour faciliter la gestion des absences au sein d'un établissement scolaire ou universitaire. Elle permet aux utilisateurs de suivre, enregistrer et analyser les absences des étudiants de manière intuitive et efficace.

## Fonctionnalités principales
- Gestion des comptes étudiants et enseignants
- Espace étudiant : consultation de ses absences, justification d’absence avec dépôt de fichier justificatif
- Espace enseignant : affichage des étudiants absents par matière, visualisation détaillée des absences (CNE, séance, date, justification, pénalité, état), modification et suppression d’absences
- Ajout d’une absence par l’enseignant
- Contact direct par email entre enseignant et étudiant
- Statistiques et rapports sur les absences
- Interface moderne, ergonomique et respectueuse de la confidentialité

## Technologies utilisées
- Kotlin
- Android SDK
- Architecture MVVM
- Room Database
- Material Design

## Installation
1. Cloner le dépôt :
   ```bash
   git clone https://github.com/Bayron98/gestion_absences_mobile.git
   ```
2. Ouvrir le projet dans Android Studio.
3. Synchroniser les dépendances Gradle.
4. Lancer l'application sur un émulateur ou un appareil Android.

## Structure du projet
- `app/` : Code source principal de l'application
- `build.gradle.kts` : Configuration Gradle
- `settings.gradle.kts` : Paramètres du projet
